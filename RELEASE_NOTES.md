## Touhou 11 — 1.00a-r3 (first release)

A native Nintendo Switch port of Touhou 11: Subterranean Animism v1.00a, built on YomotsuHisami's TH11 C++ reimplementation and compiled natively for ARM64.

* 🌸 **The full game:** all six shot types, every difficulty, all 6 stages and Extra, endings, staff roll, music room and replays.
* 🎮 **Remappable controls** through Option → Key Config (defaults match the other ports; the D-Pad and sticks only move).
* 🔊 BGM streamed straight from `thbgm.dat` with the original loop points.
* ⏳ First launch builds the dialogue font once (about 13 seconds, with a loading bar); later launches start almost instantly.
* 👆 Touch controls in handheld mode.
* 📁 Recommended folder: `sd:/switch/touhou/touhou11/` — keep every Touhou port in one `sd:/switch/touhou/` folder instead of separate folders. The NRO's own folder is always checked first, and the old locations still work.

Put `touhou11.nro`, `th11.dat`, `thbgm.dat` and `msgothic.ttc` (plus optional `msmincho.ttc`) in the folder and launch from hbmenu.
